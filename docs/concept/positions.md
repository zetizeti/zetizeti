> zetizeti's stated commitments. Each is a claim the tool can be held to, and each is something the

---

## Position 1 — Understanding is not deliverable

**→ [`position.md`](position.md)** · the founding commitment.

The tool will not deposit a conclusion, because an understanding gap is not the kind of gap a
sentence closes; and when a question mixes an information gap with an understanding gap, handing over
the words ends the part that mattered. The refusal is category fidelity, not stinginess. The
never-answer guard (`lib/dialogue.mjs` + `lib/guard.mjs`) is this position made enforceable in code.

## Position 2 — The tool measures the inquiry, never the inquirer

**→ [`measuring-the-inquiry.md`](measuring-the-inquiry.md)** · the uniqueness claim (the version
ladder's **2.0**).

The field has moved past "an LLM that asks questions" — but toward modelling the learner, to optimise
the learner. zetizeti's invariants (#5, #7) forbid exactly that, so its uniqueness is an inversion: a
deterministic mathematics of the *inquiry's* own sharpening — of the question, never the questioner.
In one line: *the only questioning tool whose mathematics is forbidden, by construction, from
modelling you.* Stated honestly as a direction the tool commits to, not a possession it already
holds — the measure is a sketch today, and the note says so.
